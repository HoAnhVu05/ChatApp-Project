========================================
CÁC LỆNH GIT ĐỂ ĐƯA CODE LÊN GITHUB
========================================

1. KIỂM TRA TRẠNG THÁI:
   git status

2. XEM CÁC FILE ĐÃ THAY ĐỔI:
   git diff

3. THÊM FILE VÀO STAGING:
   git add client.py
   git add server.py
   HOẶC thêm tất cả file đã thay đổi:
   git add .

4. COMMIT (Lưu thay đổi):
   git commit -m "Mô tả thay đổi của bạn"
   
   Ví dụ:
   git commit -m "Fix loi parse ten nhieu tu va cai thien nhap duong dan file"

5. ĐẨY LÊN GITHUB:
   git push origin main

========================================
LỆNH TẤT CẢ TRONG MỘT LẦN:
========================================
git add .
git commit -m "Mô tả thay đổi"
git push origin main

========================================
NẾU LẦN ĐẦU TIÊN SETUP:
========================================
git config --global user.name "Tên của bạn"
git config --global user.email "email@example.com"
